# Лабораторная работа №2. Алгоритмы и абстрактные структуры данных

## Описание

Решение задач 1–7 на C++17 и Go. Все программы основаны на структурах данных из ЛР1
(стек `MyStack`, массив `MyArray`, `json.hpp`), которые подключаются из соседней папки `lab1`.

## Задание

1. **Стек**, вариант 10 — строка со скобками: удалить минимальное число скобок, чтобы последовательность стала правильной (`task1_brackets.cpp`, `go/task1`).
2. **АТД «Множество»** — операции `SETADD`, `SETDEL`, `SET_AT` с хранением в файле (`task2_set.cpp`, `MySet`, `MyHashTable`, `go/task2`).
3. **Множество**, вариант 4 — среди подмножеств найти два с максимальным количеством пересечений (`task3_intersections.cpp`, `go/task3`).
4. **Массив**, вариант 4 — пирамида: максимальная высота пирамиды из блоков, ставить можно только на блок большей ширины (`task4_pyramid.cpp`, `go/task4`).
5. **Двоичное дерево**, вариант 2 — чтение АВЛ-дерева «змейкой» (`task5_snake.cpp`, `LevelAVLTree`, `go/task5`).
6. **Хеш-таблица**:
   - 6.1, вариант 2 — метод цепочек и хеширование кукушки, эмпирический анализ (`task6_analysis.cpp`, `HashTables`, `go/task6_analysis`);
   - 6.2, вариант 1 — хеш-функция методом свёртки (`task6_folding.cpp`, `go/task6_folding`).
7. **LRU/LFU**, вариант 2 — LFU-кэш с операциями `GET` и `SET` за O(1) (`task7_lfu.cpp`, `go/task7`).
